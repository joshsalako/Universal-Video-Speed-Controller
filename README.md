# Universal Video Speed Controller

Universal Video Speed Controller is a Chrome extension that lets you set one default playback speed for videos across websites.

It works on major video platforms, social media sites, and other pages that use standard web video players.

## What It Does

- Set a default video speed once
- Apply that speed automatically on supported sites
- Update open tabs after you save a new speed
- Support speeds from `0.25x` to `4x`

## Local Installation

1. Open Chrome and go to `chrome://extensions`.
2. Enable `Developer mode`.
3. Click `Load unpacked`.
4. Select this project folder.

## Usage

1. Click the extension icon in Chrome.
2. Enter a speed from `0.25` to `4`.
3. Click `Save`.
4. Play a video on your preferred site.

Your chosen speed should apply automatically. If a site does not update right away, refresh the tab once.

## Notes

- The speed value must be in `0.25` increments.
- Some heavily customized or protected video players may not respond the same way as standard web video players.
